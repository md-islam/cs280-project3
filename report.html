1.1 Constructing Noisy Training Inputs

The input is my personal clock-tower photograph, center-cropped and resized to 512×512 RGB, normalized to [−1,1]. One seed-180 Gaussian noise tensor is reused at t=0.25, 0.50 and 0.75.

x_t = (1 − t) ε + t x₁. Time 0 is noise; time 1 is the clean image. Larger t retains more image information.

The same original/noise pair is used throughout Sections 1.1–1.5. Historical export captions calling this Campanile were incorrect; image identity was checked against the saved tensor.

1.2 Classical Denoising

Before Gaussian filtering I restore image amplitude by dividing the noisy input by t: x_t/t = x₁ + ((1−t)/t) ε.

The sweep over sigma 1, 2, 4, 8 and 16 selects 8, 4 and 1 at t=0.25, 0.50 and 0.75. MSE is 0.0610792525, 0.0437529646 and 0.0250520054 respectively.

Averaging suppresses noise but also blurs edges. This is a classical baseline, not a learned denoiser.

1.3 One-Step Denoising

One-step denoising extrapolates along the predicted velocity: x̂₁ = x_t + (1−t) vθ(x_t,t,c). The prediction is velocity, not noise.

Each of the three saved noisy inputs is evaluated once using “a high quality photo.” Network evaluation and integration remain float32.

At high noise the estimate can invent or distort architectural details; higher starting times preserve more of the source.

1.4 Visualizing Velocity

I compare predicted updates (1−t)vθ with the target (1−t)(x₁−ε) = x₁−x_t. Per-pixel error is sqrt(mean_RGB((predicted update − target update)²)), before clipping or display scaling.

All predicted/target update panels share a symmetric scale with zero at middle gray. Error maps use common linear limits.

Mean RGB RMS errors are 0.1038969681, 0.0716889650 and 0.0445430838 at t=0.25, 0.50 and 0.75. Smaller errors also reflect the shrinking (1−t) update; they do not alone prove a more accurate velocity field.

1.5 Iterative Denoising with Euler Sampling

Euler recomputes velocity after each update: x_(t+h) = x_t + h vθ(x_t,t,c). Starting from the saved t=0.50 state, h=0.02 gives 25 updates and reaches t=1.00 exactly.

The trajectory shows t=0.50, 0.60, 0.70, 0.80, 0.90 and 1.00. The methods comparison uses the same noisy input.

Measured MSE: Gaussian 0.0437529646; one-step 0.0181908794; Euler 0.0217692759. One-step is numerically best in this run; iterative sampling does not guarantee better source reconstruction.

Experimental overview

A one-step denoiser can remove noise from a digit, but independent noise provides no clue to a specific target. Flow matching instead learns a velocity field that transports Gaussian noise toward the image distribution. This report follows that progression and compares class guidance, constant learning rate and extended time-only training.

B1.1

A single-step denoising UNet

The unconditional UNet maps a 28 × 28 grayscale image to an image of the same shape. Convolutional blocks use batch normalization and GELU. Two downsampling stages reduce spatial resolution to 14 × 14 and 7 × 7; a pooled bottleneck is expanded before upsampling. Concatenated encoder features preserve local detail through skip connections. The final convolution is linear.

For the denoising experiments, hidden width D = 128. The model learns to predict the clean image directly, minimizing pixelwise mean squared error (MSE).

B1.2

How noise changes the input

Clean MNIST pixels lie in [0, 1]. A single test image and Gaussian draw are held fixed while the scale changes: z = x + σε, with ε ∼ N(0, I). Noise is unclipped for computation; clipping is used only for display.

B1.2.1

Learning to remove noise

Training uses only the shuffled MNIST training split, with fresh σ = 0.5 Gaussian noise at every batch: five epochs, batch size 256, D = 128, Adam learning rate 10−4 and MSE. Fixed held-out test inputs allow an epoch-to-epoch comparison.

The loss falls rapidly early in training. Most digits are already recognizable after epoch 1; the epoch-5 predictions retain the target shapes while suppressing much of the noise. This is a visual assessment of the displayed test examples, not a measured test-set accuracy.

B1.2.2

Testing outside the training noise level

The model preserves a recognizable 7 at low and moderate noise, including the training level. At σ = 0.8 and 1.0, an extra lower stroke appears and the shape becomes ambiguous. The deterioration is most evident above the training noise level; these samples do not suggest equal failure at every departure from σ = 0.5.

B1.2.3

Why independent noise produces an average

A fresh D = 128 model repeats the five-epoch denoising setup, but its input is independent Gaussian noise and its target is a clean training digit. Adam uses 10−4 and batch size 256.

Both epochs show blurry, nearly identical central shapes with overlapping loops, rather than the distinct targets. Independent noise contains no information about which clean digit was selected. Under population MSE, the optimal prediction is the conditional mean:

D*(ε) = E[x | ε] = E[x].

Averaging differently shaped digits produces overlapping strokes. The observed similarity is consistent with this explanation; the model has not recovered a target digit from absent information.

B2.1

Predicting a flow, conditioned on time

The time-conditioned UNet uses D = 64. Two fully connected blocks embed one scalar time per image; their channel vectors multiply the expanded bottleneck and first upsampling features. The model predicts velocity rather than a clean image or noise.

xt = (1 − t)x0 + tx1,   u = x1 − x0.

Here x0 is independent standard Gaussian noise, x1 is a clean MNIST image, and t is sampled continuously and uniformly from [0, 1). Training minimizes MSE between uθ(xt, t) and u. Time runs from noise at 0 toward data at 1.

B2.2

Training the time-conditioned model

Ten epochs use batch size 64, Adam initialized at 0.01, and an exponential learning-rate scheduler with γ = 0.11/10, stepped after each epoch. Independent noise and continuous times are sampled anew for each fetched batch.

B2.3

Sampling the time-conditioned flow

Euler integration starts from 40 independent Gaussian images and updates x ← x + uθ(x, t)/50 at t = k/50, k = 0,…,49. The same CPU-generated initial noise (seed 184) is used for each checkpoint. Inference uses evaluation mode and disables gradients.

Epoch 1 contains many fragments. Later samples form more coherent digits, although several shapes remain ambiguous at epoch 10. This motivates the graduate continuation experiment below.

B2.4

Adding class conditioning

The class-conditioned model retains D = 64 and adds two fully connected embeddings of one-hot labels 0–9. At the two conditioning sites, the class embedding scales the feature map and the time embedding is added: h ← ci ⊙ h + ti.

Training independently drops each example’s class vector with probability 0.1 by setting it to zero. This null conditioning supports both conditional and unconditional velocity predictions for classifier-free guidance (CFG).

v = vuncond + 5(vcond − vuncond).

B2.5

Training the class-conditioned model

Training uses the same noise-to-data interpolation and velocity MSE, ten epochs, batch size 64, Adam with initial learning rate 0.01 and exponential decay γ = 0.11/10. The only new input is the class label with 10% dropout.

B2.6

Guided class-conditioned samples

Each checkpoint uses 300 Euler steps, CFG scale 5.0 and the same initial-noise seed 185. Columns request digits 0–9, repeated across four rows: four instances of every digit, forty images per checkpoint.

The requested digit structure is already visible at epoch 1. Later grids show mostly legible, class-consistent outputs with differences in stroke width, loop shape and slant. These are qualitative observations, not a measured classification score.

B2.6 · independent comparison

Removing the learning-rate scheduler

A fresh, independent class-conditioned D = 64 model trained for ten epochs with batch size 64, the same flow objective and 10% class dropout. Adam used a constant learning rate of 0.003, with no scheduler. This rate is near the baseline’s epoch-6 rate: a compromise between its 0.01 start and approximately 0.001 finish, rather than keeping the initial rate throughout. It was a single-run choice, not an established optimum.

CS 280A Graduate Bells & Whistles: Improved Time-conditioned UNet

The original time-only model was continued from epoch 10 through epoch 30, using twenty additional epochs. Its checkpoint and Adam optimizer state were restored. Learning rate began at 0.001 and future decay was slowed to γ = 0.11/20. The D = 64 architecture, flow objective and batch size 64 were retained; no class conditioning was added.

The comparison holds initial noise seed 184 and fifty Euler steps fixed. The epoch-10 baseline is reused from the original sampling result where available.

The visual gains are modest and nonuniform. Within each four-row grid, row 2, column 1 becomes more connected and 4-like; row 3, column 9 becomes a clearer closed loop.
